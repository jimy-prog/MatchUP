# MatchUp — Sports Matchmaking Platform

A modern sports matchmaking and venue booking platform built for Uzbekistan.

## Tech Stack
- React 19 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Firebase (Auth + Firestore)
- Framer Motion
- Leaflet Maps

## Getting Started
```bash
npm install
npm run dev
```

## Environment Variables
Copy `.env.example` to `.env` and fill in your Firebase config.

## Features
- Discover matches by sport, location, time
- Create and join games
- Browse and book venues
- Player ratings and leaderboard
- Role-based access (Player, Owner, Developer)
